# PHP – Exercícios e Projetos

Este repositório contém exercícios e pequenos projetos em **PHP**, desenvolvidos durante meus estudos da linguagem e da programação web com backend.

O objetivo é registrar práticas com lógica, formulários, sessões, arrays e arquivos, além de consolidar conhecimentos básicos de PHP em aplicações simples.

---

## Conteúdo do repositório

| Arquivo / Pasta | Descrição |
|-----------------|-----------|
| `index.php` | Exemplo de página inicial em PHP |
| `formulario.php` | Formulário simples com tratamento de dados |
| `exercicios/` | Pasta com exercícios de lógica e uso de PHP |
